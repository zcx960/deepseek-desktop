# Official Chat Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Add a persistent official DeepSeek Chat surface to the Tauri desktop app with a top-level Harness/Chat switch and independent failure/storage boundaries.

**Architecture:** Keep the existing React shell and Harness iframe. Add a Rust-owned Tauri child WebView with a dedicated data directory, explicit navigation policy, and manual bounds below the shell navbar. A React store persists the selected mode and coordinates shell commands/events.

**Tech Stack:** Tauri 2, Rust, React 19, TypeScript, Valtio Define, HeroUI, i18next, Vitest.

## Global Constraints

- Preserve the current Harness iframe and Rust process lifecycle.
- Chat storage must be isolated from Harness storage.
- All user-facing strings must be localized in `en-US.json` and `zh-CN.json`.
- Rust errors use uppercase prefixes and all URL policy decisions happen in Rust.
- Run `pnpm typecheck`, focused Vitest tests, `cargo check`, and focused Rust tests.
