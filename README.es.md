# DeepSeek Desktop Chat

Este repositorio ahora utiliza la aplicación Tauri de `dsh-tauri/deepseek-harness-desktop` e incorpora los modos Harness y Chat. La documentación actual de esta versión está disponible en [inglés](README.en.md) y [chino simplificado](README.md).

Descarga las versiones con la etiqueta `chat-build-` desde [Releases](https://github.com/zcx960/deepseek-desktop/releases). Los instaladores no están firmados; Chat integrado requiere macOS 14 o posterior. La versión Electron anterior permanece en el historial de Git.
